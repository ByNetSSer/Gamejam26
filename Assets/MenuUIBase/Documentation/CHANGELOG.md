# Changelog

## 1.0.0 - 2026-10-27

- Rebuilt the project as a generic menu and persistent-audio foundation.
- Added independent Runtime, Demo and Editor assemblies.
- Added saved master, music and sound-effects volumes.
- Added music transitions and duplicate-service protection.
- Added asynchronous scene loading, panel navigation and pause support.
- Added two generated demo scenes with no bundled media assets.
- Removed game-specific authentication, character, door and minigame code.
